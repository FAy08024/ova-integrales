SECCIÓN 3 · REGIONES DE INTEGRACIÓN

Regiones Tipo I y Tipo II

¿Qué son las regiones de integración?

Las regiones de integración determinan los límites dentro de los cuales se evalúa una integral doble.

Cuando una región está delimitada por curvas, los límites de integración pueden depender de otra variable.

Regiones Tipo I

Una región Tipo I se describe utilizando límites constantes para X y funciones de X como límites para Y.

Su representación general es:

a ≤ x ≤ b

g₁(x) ≤ y ≤ g₂(x)

Regiones Tipo II

Una región Tipo II utiliza límites constantes para Y y funciones de Y como límites para X.

Su representación general es:

c ≤ y ≤ d

h₁(y) ≤ x ≤ h₂(y)

Ejemplo práctico

Consideremos una región limitada por:

y = x² y y = x.

Estas curvas se intersectan en los puntos (0,0) y (1,1).

Podemos describir la misma región mediante secciones verticales u horizontales.

Para la función f(x,y) = x + y, la integral sobre esta región tiene como resultado:

3/20 = 0.15

Interpretación gráfica

Las secciones verticales y horizontales permiten comprender cómo se establecen los límites de integración.
