Desarrollo matemático paso a paso

Resolución analítica de la integral doble para un router ubicado en el centro del salón.

Paso 1. Definir el modelo Wi-Fi

Se utiliza la función hipotética de intensidad de señal:

\[ S(x,y)=-40-(x-a)^2-(y-b)^2 \]

Para el router ubicado en (5,4):

\[ \boxed{S(x,y)=-40-(x-5)^2-(y-4)^2} \]

Paso 2. Definir la región de integración

El salón mide 10 metros de largo y 8 metros de ancho.

\[ R=\{(x,y):0\le x\le10,\ 0\le y\le8\} \] \[ A=10(8)=80\ \mathrm{m}^2 \]

Paso 3. Plantear la integral doble

\[ I=\iint_R S(x,y)\,dA \]

Aplicando el teorema de Fubini:

\[ I=\int_0^{10}\int_0^8 [-40-(x-5)^2-(y-4)^2]\,dy\,dx \]

Paso 4. Integrar primero respecto a y

Durante esta integración, x se considera constante.

\[ \int[-40-(x-5)^2-(y-4)^2]\,dy \]

La primitiva es:

\[ -40y-(x-5)^2y-\frac{(y-4)^3}{3} \]

Evaluamos desde y = 0 hasta y = 8:

\[ \left[ -40y-(x-5)^2y-\frac{(y-4)^3}{3} \right]_0^8 \]

El resultado de la integral interna es:

\[ \boxed{-\frac{1088}{3}-8(x-5)^2} \]

Paso 5. Integrar respecto a x

Sustituimos el resultado anterior:

\[ I=\int_0^{10} \left[-\frac{1088}{3}-8(x-5)^2\right]dx \]

Calculamos la primitiva:

\[ -\frac{1088x}{3} -\frac{8(x-5)^3}{3} \]

Evaluamos entre 0 y 10:

\[ I=\left[ -\frac{1088x}{3} -\frac{8(x-5)^3}{3} \right]_0^{10} \] \[ \boxed{I=-\frac{12880}{3}} \]

Paso 6. Comprobar el otro orden de Fubini

Ahora integramos primero respecto a x y después respecto a y.

\[ I=\int_0^8\int_0^{10} [-40-(x-5)^2-(y-4)^2]\,dx\,dy \]

La primitiva respecto a x es:

\[ -40x-\frac{(x-5)^3}{3} -x(y-4)^2 \]

Evaluando entre x = 0 y x = 10:

\[ \boxed{-\frac{1450}{3}-10(y-4)^2} \]

Integramos respecto a y:

\[ I=\int_0^8 \left[-\frac{1450}{3}-10(y-4)^2\right]dy \] \[ I=\left[ -\frac{1450y}{3} -\frac{10(y-4)^3}{3} \right]_0^8 \] \[ \boxed{I=-\frac{12880}{3}} \]

Ambos órdenes de integración producen el mismo resultado, verificando el teorema de Fubini para este modelo.

Paso 7. Calcular el promedio espacial

Dividimos la integral doble entre el área total del salón:

\[ \overline{S}=\frac{1}{A}\iint_R S(x,y)\,dA \] \[ \overline{S} =\frac{-12880/3}{80} =-\frac{161}{3} \] \[ \boxed{\overline{S}\approx-53.67\ \mathrm{dBm}} \]

Este valor representa el promedio espacial aritmético de la señal expresada en dBm bajo el modelo hipotético.
